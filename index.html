報告を保存するには、GitHub の「Fine-grained personal access token」をこの端末に登録します（このブラウザ内にだけ保存されます）。

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → zaitaku-report
  3. Permissions → Repository permissions → Contents：Read and write
  4. 生成されたトークン（github_pat_…）を下に貼り付け
